## Description

```sql
CREATE VIEW site_admins AS (
 SELECT g.id,
    p.discord_id,
    p.auth_user_id,
    g.person_id,
    g.created_at
   FROM (guild_grants g
     JOIN people p ON ((p.id = g.person_id)))
  WHERE (g.grant_type = 'site_admin'::text)
)
```
