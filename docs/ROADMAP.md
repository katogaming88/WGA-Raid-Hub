# WGA Raid Hub Roadmap

The roadmap lives on the issue tracker, not here.

- **[Milestones](https://github.com/katogaming88/WGA-Raid-Hub/milestones)** hold the planned
  work, grouped by the question each part answers.
- **[#947](https://github.com/katogaming88/WGA-Raid-Hub/issues/947)** pins the build order
  across the milestones that run in parallel, and records every change to that order with
  the reason for it.
- **[CHANGELOG.md](../CHANGELOG.md)** is what has shipped, by release.
- **[STRESS_TEST.md](STRESS_TEST.md)** is the smoke-testing practice: those checklists live
  on their own issues and run when the real-world trigger for each happens.

This file used to carry the list itself. It described the Google Apps Script backend that
was retired in July, and all six of its unchecked items were closed issues by the time it
was retired in turn (#958). The old list is in git history.
